 📌 Smart Task Reminder Dashboard

 📝 Overview

The **Smart Task Reminder Dashboard** is a web-based application designed to help users manage daily tasks efficiently. It allows users to create tasks with specific time schedules and provides real-time reminders using visual alerts and sound notifications.

The application also supports customization features such as uploading a profile image, setting a background image, and selecting custom alarm sounds, making the user experience interactive and personalized.



 🎯 Objectives

* To build an **interactive task management system** using web technologies
* To implement **time-based reminders with sound alerts**
* To provide a **user-friendly and customizable dashboard UI**
* To ensure **persistent data storage** using browser local storage
* To enhance productivity through **real-time task notifications**



 ⚙️ Features

* ✅ Add, view, and delete tasks
* ⏰ Time-based task reminders
* 🔔 Automatic alarm with repeating notifications
* 🔘 Manual "Remind Now" button for instant alerts
* 🔊 Custom alarm sound upload
* 🖼 Profile image upload (round display)
* 🌄 Background image customization
* 💾 Local storage for saving tasks and preferences
* 🎨 Interactive UI with styled buttons and layout

 📊 Dashboard Details

The dashboard is designed with a **card-based horizontal layout** that includes:

* **Profile Section**: Upload and display user image in circular format
* **Background Section**: Customize dashboard appearance
* **Alarm Section**: Upload and manage notification sounds
* **Task Input Section**: Add tasks with time scheduling
* **Task List Section**: Centrally aligned task display with:

  * Task name and time
  * Reminder button
  * Delete option
  * Highlighted active task during alerts

The system continuously checks task timing and triggers alarms with visual and audio cues to ensure tasks are not missed.
